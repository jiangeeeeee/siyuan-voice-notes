# 思源语音 Pro

Voice Notes Pro 为 29.9 元永久授权，绑定思源账号，同一账号可在多台设备使用同一码。适用于 Lite 和 Full。

| 功能 | 操作入口 | 完成后的效果 |
| --- | --- | --- |
| 正文与音频同步 | 播放器下方开启“同步正文笔记与音频”，播放后输入正文 | 段落右侧出现回听按钮 |
| 专业词库与纠错 | 插件设置中的“管理全局词库”，或语音块“更多操作”中的“本条录音附加词库” | 预览确认后修正当前录音的术语 |
| 精确原音双链 | Ctrl / Command 点击波形两处，复制所选音频链接，再与正文关联 | 从正文回听原音，从来源语段跳回引用正文 |

## 激活

点击语音块右上角的 Pro，复制当前思源账号 ID。通过窗口中的淘宝链接购买并领取授权码后，粘贴到“永久 Pro 授权码”，点击“激活 Pro”。确认窗口显示“永久 Pro 已激活，可离线使用”。

## 按步骤使用

[完整图文说明](使用说明.md) 包含授权、播放及录音同步、词库增删导入导出、校对预览、音频选区、双链和回听管理的逐步按键说明，以及九张效果图。

词库的纠错需要预览确认。正文同步在播放或录音过程中记录实际输入的时间。建立范围双链时，Mac 使用 Command 点击两处，Windows 使用 Ctrl。
