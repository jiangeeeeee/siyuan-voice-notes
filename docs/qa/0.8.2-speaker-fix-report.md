# 0.8.2 发言人修订排查报告 · 2026-11-13

版本仍为 0.8.2。本报告仅覆盖发言人识别、归属、资源复用和音轨右键操作。

## 根因与判断依据

- offline/worker.js 原来不传配置，调用上游默认模型：pyannote segmentation 3.0 + 中文 3D-Speaker ERes2Net base；16 kHz 单声道，CPU/单线程 WASM。
- 默认人数未知（numClusters=-1），余弦距离完整链接聚类，阈值固定 0.5；语音最短开启 0.3 秒，关闭间隔 0.5 秒。不是凭正文、姓名或音量判断人物。
- src/speakers.ts 原按最长重叠时间给整句话指定一个人，跨人物边界和重叠讲话也会被强行赋值。
- 每次分析建立新的 Worker，加载并销毁模型；每次对全音频重新推理。
- 再分析时重新生成匿名人物，没有按时间重叠复用旧人物，名字会累积变化。

上游依据：
- [1.12.20 聚类源码](https://github.com/k2-fsa/sherpa-onnx/blob/v1.12.20/sherpa-onnx/csrc/fast-clustering.cc)
- [1.12.20 官方示例与阈值说明](https://github.com/k2-fsa/sherpa-onnx/blob/v1.12.20/python-api-examples/offline-speaker-diarization.py)
- 本地 offline/models.json 与发行包 diar/sherpa-onnx-speaker-diarization.js。

## 修改

1. 增加每条录音的实际人数与聚类阈值输入，成功分析后保存参数。
2. 只有完整覆盖且人物唯一时才给正文自动赋值；交叠、跨人和覆盖不足保留混合/未指定。手工更正优先。
3. 重新分析按时间多数重叠进行一对一人物复用；空/无效结果不清空原数据。
4. 两分钟内复用空闲人物模型和相同音频/参数的结果；音频按实际 PCM 内容哈希，不单按路径判断。取消、错误、插件关闭及闲置超时释放资源。
5. 录音已有完整人工区间时跳过自动分析；提供实际已用时间，不伪造推理百分比。
6. 音轨右键提供单区间变更/清除、整个人物管理；旧版语段标签兼容。单区间清除不会延长前一个区间，不删除原音、正文或引用。

## 实际限制

已知人数解决的是聚类人数约束，不等于逐时间段正确率。没有本用户录音的人工标注参考，未计算 DER 或承诺准确率提升百分比。
第一次长录音仍完整走单线程 WASM，未声称本次提高首次模型推理速度。复用模型主要省加载；相同音频和参数的结果复用才省整个重复推理。
没有通过盲目切段分别聚类来加速，避免同一个人在各段得到不同身份编号。
