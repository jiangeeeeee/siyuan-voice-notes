# 思源语音 Voice Notes

在思源正文中录音、整理逐字稿，并从笔记回听对应的原话。当前版本为 0.8.2，包含 2026 年 11 月 13 日的发言人修订，要求思源 3.8.9 或更新版本。

## 下载与安装

请从 [Releases](https://github.com/jiangeeeeee/siyuan-voice-notes/releases/latest) 下载安装包。

- `package.zip` 是完整 Lite 安装包，支持录音、导入、播放、字幕和笔记整理。
- Full 包包含本地转写及发言人模型，文件较大，以 `.001`、`.002` 两部分提供。下载两部分并按 [Full 安装说明](INSTALL-FULL.txt) 合并后再解压。第二模型的便携运行组件适用于 Windows x64。

退出思源，将安装包内容解压至工作空间的 `data/plugins/siyuan-voice-notes`，让 `plugin.json` 直接位于此目录，再启动思源并启用插件。升级前备份工作空间，保留正文、`assets` 和插件存储中的录音及授权数据。Lite 与 Full 使用同一个插件目录。

## 功能

- 在正文指定位置开始录音，支持暂停、继续和快捷键。可以批量导入已有音频，并配对 SRT、VTT、TXT 字幕。
- 播放支持倍速、循环、波形和时间定位。录音中或回听时可以添加时间标记及备注。
- Full 提供普通话、英语、粤语的本地转写。逐字稿可编辑、搜索、按人物筛选、拆分、合并，也可选择一段音频重新识别，核对后替换文字。
- 可预设参会人、录音中切换发言人，或在录音后自动区分。自动分析支持填写实际人数和调整聚类阈值，音轨色条可右键变更或删除当前区间的发言人标注。
- 支持语段标签、批注和自定义批注类型，提供 TXT 导出、结构化 JSON 导入导出、修改撤销和未保存录音草稿恢复入口。
- 正文可以关联音频中的固定时间范围，从正文回听原音，也可以从来源语段查看引用它的笔记。
- Windows x64 Full 提供 SenseVoice 与 Qwen3-ASR 双模型复核，分别生成候选供人工回听、编辑和选择。

## 免费功能与 Pro

录音、导入、播放、时间标记、发言人管理、字幕、逐字稿手动编辑、批注和导出均免费。离线识别需要 Full 资源，与 Pro 授权分开。

Pro 为 29.9 元永久授权，包含三项功能。

1. 正文笔记与录音或播放时间自动同步。
2. 全局及单条录音的专业词库管理、词库辅助校对与批量纠错。
3. 精确原音双链的创建和重新定位，包括 Ctrl（macOS 为 Command）选择音频范围后与正文建立关联。

在语音块右上角或插件设置中点击 Pro，可复制思源账号 ID、打开淘宝购买入口并输入授权码。授权绑定思源账号，同一账号可在多台设备使用同一码，在本机完成离线校验。

## 数据与平台

音频保存在工作空间的 `assets`，逐字稿、人物、时间标记和批注保存在思源原生自定义块中。JSON 备份保存结构化数据和资源路径，完整迁移需同时保留原音频及相关文档。

Lite 不含离线模型。Full 中第二模型的便携运行组件为 Windows x64 版本，macOS、Linux 和移动端的完整 Full 套件尚未验收。媒体格式支持取决于宿主解码器。

自动转写和人物区分仍可能出错，尤其是专业词、短促插话和多人同时讲话。请回听并校对重要内容。首次长录音分析仍需本机完整计算，相同音频和参数的分析结果可在两分钟内复用。
