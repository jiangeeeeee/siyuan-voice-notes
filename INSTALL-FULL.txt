思源语音 Voice Notes 0.8.2 Full 安装说明

下载所有 siyuan-voice-notes-0.8.2-full.zip.数字 分卷，放在同一个文件夹。各分卷是按字节拆分的 ZIP，先按编号顺序合并，再解压。当前共 17 个分卷，从 .001 到 .017，请下载齐全。

Windows PowerShell（在分卷所在文件夹运行）
$voiceOutput = [System.IO.File]::Create((Join-Path (Get-Location) "siyuan-voice-notes-0.8.2-full.zip"))
try { Get-ChildItem "siyuan-voice-notes-0.8.2-full.zip.???" | Sort-Object Name | ForEach-Object { $voiceInput = $_.OpenRead(); try { $voiceInput.CopyTo($voiceOutput) } finally { $voiceInput.Dispose() } } } finally { $voiceOutput.Dispose() }

macOS / Linux 终端
cat siyuan-voice-notes-0.8.2-full.zip.[0-9][0-9][0-9] > siyuan-voice-notes-0.8.2-full.zip

SHA256SUMS.txt 同时列出分卷和合并后 ZIP 的校验值。合并包已包含 11 月 13 日的发言人修订，无需再安装该修订补丁。

退出思源并备份工作空间。将 ZIP 解压至工作空间 data/plugins/siyuan-voice-notes，plugin.json 应直接位于此目录。保留正文、assets 及 data/storage/petal/siyuan-voice-notes 中的数据。升级时先将旧插件程序目录移到工作空间之外，再放入完整新包。

Full 内第二模型 Qwen3-ASR 的便携运行组件适用于 Windows x64。macOS、Linux 和移动端的完整 Full 套件尚未验收。Windows 解压时若提示路径过长，请使用支持长路径的工具或较短的工作空间路径。

package.zip 为 Lite 安装包，不含离线模型。源码查看或下载按钮提供的是公开仓库文档，安装请使用 Release 附件。
