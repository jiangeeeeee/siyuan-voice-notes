# 思源语音 Full

思源语音分为 [Lite](https://github.com/jiangeeeeee/siyuan-voice-notes-lite) 和 [Full](https://github.com/jiangeeeeee/siyuan-voice-notes)：Lite 不带识别模型，适合录音、回听、导入字幕和手工整理；Full 在这些功能之上附带本地转写及发言人模型，Windows 双模型复核另有完整扩展包。本仓库发布 Full，两种版本都可以在思源正文中保存录音与整理结果。

比如听完一节课，你可以先按时间标记找出没听懂的地方，再把自己的解释写进正文，给这段解释附上原音链接。过几天复习时，点笔记里的链接，就能听到老师当时的完整说法。

## 先把声音放进笔记里

打开正在记笔记的文档，从面包屑上的录音按钮或块菜单开始录音。可以暂停、继续，也可以设置一个在思源窗口内使用的录音快捷键。结束后，录音会保存在正文中的语音块里，旁边保留原始音频链接。

已经用手机或其他录音工具录好的文件，也可以直接导入。支持一次选择多个音频；常见的 M4A、MP3、WAV、AAC、FLAC、OGG、OPUS、WebM 等格式是否能播放，取决于当前设备的解码能力。遇到不支持的格式时，可以先转换成 WAV 或 MP3。

如果手头还有字幕，把音频和 SRT、VTT 或 TXT 一起导入即可。同名字幕会与音频配对；只导入一个音频时，也可以配上不同名的字幕。只有文字、没有时间戳的内容仍能整理，补上时间后才可以准确回听。

## 一段长录音，只留下想再听的几分钟

先播放到大致位置，再拖动时间轴的“缩放”。滑块每移动相同距离，可见时长就按相同比例变化。播放指针在画面内时会留在原处，方便你从整堂课逐步放大到一句话。也可以用方向键微调缩放滑块。

打开语音块右上角的“更多操作 → 裁剪录音”。选“只保留这些段”时，每行填一个起止范围，例如 `12:30 - 14:10`。想剪去休息或闲聊，就选“删除这些段”。也可以先按住 Ctrl（Mac 上也可用 Command）在音轨点两处，再打开裁剪，选好的时间会自动带入。

点“生成并试听”会把保留的片段按原顺序拼好，显示新文件的大小。听过接缝后，再点“确认替换录音”。如果原文件还被别的笔记引用，思源会保留它；确认无人引用后，插件会清理这份旧资源。

例如，笔记链接原先指向第 32 分钟，剪掉开头 30 分钟后，点同一条链接就会定位到新音频的第 2 分钟。只剪掉引用的一部分时还能听剩下的内容；整段都剪掉时，会提示原音已裁掉。转写和批注文字会保留，保留范围内的时间标记与发言人位置会随录音移动。

## 听到重点，先留一个时间标记

听课时常常来不及把解释完整记下来。可以先在录音中打一个标记，写下“公式推导”“这里没听懂”之类的简短备注。整理时点击标记，就能回到当时的位置。

标记也可以在回听时补充。标记列表与波形时间轴配合使用，适合把一段长录音拆成几个能找到的重点。插件会保留尚未提交的标记草稿，方便回到原来的录音继续整理。

## 播放时，既能看时间，也能看谁在说话

语音块提供播放、暂停、前后跳转、音量、循环和倍速控制，速度可在 0.5 到 2 倍之间选择。波形可以缩放和移动，点击某处即可定位；较长的录音也不必一直拖动整条进度条。

开会前可以录入参会人名单，录音时切换当前发言人。音轨上的不同颜色表示不同人物的发言区间。发现某一段人物标错了，可以右键点击该区间，变更发言人或删除标注。删除的是人物标注，原音频仍然保留。

人物名单、切换记录和逐字稿中的人物标注都可以人工整理。插件会区分自动分析与人工修改，重新分析时尽量保留已经确认的人工标注。

## 逐字稿可以慢慢整理，不必一次改完

逐字稿是按语段保存的文字。每段可以有起止时间、发言人、标签和批注。点击已有时间定位的语段，可以回听对应原音，边听边修改。

可以搜索文字、标签和批注，也可以只看某位发言人的内容。某一段过长时可以拆分，连续的两段也可以合并。修改文字后，原始文本会保留在编辑界面中，便于核对和恢复。

例如，把课堂录音中的“定义”“例题”“待确认”分别加上标签，复习时就能按自己的问题查找。批注用于写下理解、疑问或后续行动；批注类型可以自定义，适合不同课程和会议的整理习惯。

## 从自己的笔记回到原话

正文与音频同步功能可以把记笔记的时间与录音或播放位置关联起来。之后回看某一段正文时，可以从对应时刻回听。还可以设置 0–30 秒的回听提前量，让播放从这句话之前稍早一点开始，保留必要的上下文。

如果只想引用一句话，可以按住 Ctrl（macOS 使用 Command），在音轨上点击两处，选出一段明确的时间范围，再把原音链接放进正文。已有时间定位的逐字稿语段也可以复制成音频链接。

这里的“双链”指两个方向：从正文能回到原音，从语音块也能查看哪些正文引用了它。引用保存的是音频的具体范围，便于以后修改自己的总结，同时保留原话供核对。

## 把常见的人名和术语整理成词库

课程名、项目缩写和专业术语很容易反复写错。可以建立全局词库，让多条录音共用；也可以给某一条录音追加专用词条。

纠错规则保存“原词 → 正确写法”的对应关系。应用时先查看替换预览，确认后再修改逐字稿，并提供撤销入口。它按你确认的规则整理文字，不会仅凭上下文猜测某个陌生词应该怎么改，因此人名和关键术语仍建议回听确认。

## 整理结果可以带走

逐字稿可以导出为 UTF-8 文本。结构化 JSON 还会保留语段时间、人物、标签、时间标记和批注，适合备份或重新导入。替换已有语音数据前会保存备份，批量纠错等操作也有对应的撤销入口。

录音意外中断时，可以从“恢复未保存录音”查看本机留下的草稿。草稿能否恢复取决于浏览器存储和录音片段是否仍在，重要录音请及时正常结束并保存。

音频文件保存在思源工作空间的 `assets` 中，语音数据保存在原生自定义块里。JSON 保存的是资源路径，并不把音频文件装进去；迁移工作空间时，需要把音频和相关文档一起带走。

## Full：在本机把声音转成文字

Full 的集市安装包附带 SenseVoice 主转写模型和发言人分析模型，安装后可以处理已有音轨，也可以在录音时开启实时转写。提供普通话、粤语和英语的识别选项。模型在本机处理音频，首次启动需要加载资源，处理速度取决于录音长度和设备性能。

某一小段识别不理想时，可以选中连续语段，或按住 Shift 在波形上拖出范围，只重新识别这一部分。新结果会先供你核对，确认后才替换原文字。旧语段中的批注会归档保留。单次局部识别最长五分钟，较长内容建议分段处理。

自动区分发言人依据声音特征判断“哪些片段可能是同一个人说的”，不会自动得知真实姓名。知道实际人数时，可以填写人数；不确定时可以让模型估计，并调整区分阈值。分析完成后，再把匿名人物改成参会人的名字。短促插话、背景噪声和多人同时讲话仍可能分错，右键音轨人物区间即可人工修正。

### 双模型复核适合检查拿不准的片段

Windows x64 的完整扩展包还包含 Qwen3-ASR 和对应运行组件。选定一段音频后，可以让两个模型分别给出候选文字，回听原音、比较差异，再决定采用或编辑哪一份。两个模型不一致只说明值得检查，不代表其中一个一定正确。

这项扩展需要单独安装完整包，集市的 `package.zip` 已包含日常使用的主转写与发言人模型，但不包含体积较大的第二模型运行环境。双模型一次最多处理五分钟；第二模型当前不提供逐词时间戳，也不能在 macOS、Linux、浏览器或手机中运行随包提供的 Windows 程序。

### 模型留在当前设备，录音与笔记仍可同步

Full 启用时会将自己的 `offline` 目录加入思源同步忽略列表，覆盖其中的主转写模型、发言人模型、第二模型和运行组件。这样日常云同步仍传递录音和笔记，不必在每台设备之间反复传输大模型。

换一台设备后，需要在那台设备上单独安装模型；已经同步的逐字稿仍可以阅读和编辑。在“版本与模型”中可以检查并修复同步排除规则，以及校验离线资源。排除规则仅针对思源同步，首次安装后请先启用插件、确认规则生效再开始同步；此前已上传的历史模型数据不会因此立即从云端历史中清除。外部网盘对整个文件夹的同步需要在网盘中另设排除规则。

## 从哪里开始

需要思源 3.8.9 或更新版本。先录一小段音频，添加一个时间标记，再点击标记回听，就能熟悉基本用法。麦克风录音需要系统授权；媒体格式和性能以实际设备为准。
